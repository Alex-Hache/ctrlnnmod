# M2 — bord : run libre des blocs, même W₀ (oscillateurs, classe `blockp`)

## Protocole et critères (écrits le 2026-10-21, avant tout calcul)

Question : `blockp` échoue (test 0,18 à 0,37) alors que le maître est dans S (marge 0,006 à 0,009). M1 montre que `blockp` reste sur ∂S tout le run. Est-ce le bord, ou les équations elles-mêmes ?

### Bras (16 états, 8 têtes de 2, toutes à porte, ρ = 0,999)

- **P-sat** : `blockp`, init par défaut. r brut ≈ 5 > ρ, donc W₀ = Φ(θ₀) est sur ∂S.
- **F** : mêmes équations, s ≡ 1 (les paramètres sont W). Init W₀ = Φ(θ₀) de P-sat. Mêmes autres paramètres.
- **P-int** : `blockp`, (Ã_h, B̃_h) multipliés par 0,9ρ / r_h. Alors r_h = 0,9ρ, Φ = identité, et W₀' = 0,9·W₀ sur (A, B). P-int est égal au libre issu de W₀' tant que toutes les têtes ont r_h < ρ.
- **REN** : témoin, même graine.

Optimiseurs : Adam (configuration de l'échec observé) et GD pur. Les deux gardent le clip 10 de `oscillator.run` : il change la longueur du pas, pas sa direction. 2000 itérations. 5 graines (0 à 4). Graine = maître, entrées et init, comme `oscillator.run`.

Choix du pas (règle fixée avant calcul) : test rapide sur la graine 0, 500 itérations. Pour chaque (bras, optimiseur), garder le pas de plus faible perte **d'entraînement** à 500 itér. Grilles : Adam {3e-3, 1e-2} ; GD {0,03 ; 0,1 ; 0,3 ; 1}. Puis lancer la graine 0 complète et lire les diagnostics avant les graines 1 à 4.

Journal (toutes les 50 itér.) : perte d'entraînement ; marge m(t) = ρ − maxₕ rₕ(W) (négative si W sort de S) ; nombre de têtes hors de l'intérieur ; r brut max (bras proj). Fin : erreur de test (T = 300).

### Contrôles (sinon, ne pas conclure)

- c1 : perte de F en W₀ = perte de P-sat en θ₀ (écart relatif < 1e-6).
- c2 : P-int en θ₀' : Φ(θ₀') = θ₀' et marge = 0,1ρ ; P-sat en θ₀ : marge = 0.

### Critères (mesure : erreur de test, médiane sur 5 graines ; « réussit » < 0,05, « échoue » > 0,2)

Sur Adam :
- **Bord confirmé** : F < 0,05 ou P-int < 0,05, **et** P-sat > 0,2. Puis lire m(t) de F : vers l'intérieur de S (m > 0) ou hors de S (m < 0).
- **Pas la contrainte** (Q0 réfutée pour les blocs) : F > 0,2.
- Sinon : ambigu.
- Critère secondaire : part de l'écart P-sat → REN fermée par F et par P-int (sur les médianes). ≥ 80 % : fermé ; < 20 % : non fermé.

Note : P-sat, graine 0, Adam 1e-2 donne 0,18 à 0,20. Le seuil 0,2 est donc limite pour P-sat. Je garde les seuils de la roadmap ; le critère secondaire sert seulement à lire une zone ambiguë.

Validité de GD (T1–T3 parlent de GD) : GD P-sat > 0,2 **et** GD REN < 0,05. Sinon, conclure sur Adam seulement.

Lecture prévue :

| F | P-int | P-sat | Cause | Suite |
|---|---|---|---|---|
| réussit | réussit | échoue | init saturée : piège sur ∂S (direction radiale perdue) | init dans S ; la contrainte n'est pas en cause |
| réussit | échoue | échoue | bord : la contrainte gêne même depuis l'intérieur | lire m(t) de F ; faire varier la marge du maître |

Calcul : local (Modal non configuré dans ce conteneur). ≈ 40 runs × ≈ 90 s sur 2 cœurs, ≈ 30 min.

## Contrôles (faits)

- c1 : perte F(W₀) = perte P-sat(θ₀) = 0,888877 (écart 0) ; W identiques.
- c2 : P-int : Φ(θ₀') = θ₀' (écart 0), marge 0,0999 ; W₀' − 0,9·W₀ = 4e-9. P-sat : marge −1e-7 (sur ∂S, arrondi float32).
- Contrôle ajouté (lecture du résultat) : le maître est représentable **exactement** avec les 8 têtes sur ∂S (r_h = ρ). Une tête à porte z reproduit 0,99·R(θ) avec ‖A_hh‖₂ = ρ si |0,99 e^{iθ} − (1 − z)| = ρz : racine z ∈ (0, 1) pour chaque angle (z = 0,125 ; 0,618 ; 0,911 ; 0,970). Les 4 têtes en trop : A_hh = ρI, état nul, non lues. Perte train 3e-30, test 1e-29 (`m2_teacher_on_boundary.py`). Donc un échec de P-sat n'est pas un défaut de capacité sur ∂S.

## Lecture

1. Les équations blocs ne sont pas en cause : sans contrainte, elles apprennent aussi bien que le REN (0,0015 contre 0,0051).
2. La métrique n'est pas en cause pour ce cas (M1 : κ ≤ 440, plus faible que le REN). Le terme qui reste est le **bord** (T3) : le flot libre sort de S tout de suite, donc aucun flot contraint ou riemannien ne peut le suivre.
3. Le piège n'est pas seulement l'init saturée : partie de l'intérieur (marge 0,1), P-int touche ∂S au premier pas et y reste. Le gradient pousse hors de S dès le départ.
4. L'échec contraint est un échec d'optimisation **sur ∂S**, pas de capacité : le maître est représentable exactement avec toutes les têtes sur ∂S (contrôle ci-dessus).
5. Conséquence pour l'affirmation centrale (« la métrique, plus que l'ensemble, gouverne l'entraînabilité ») : sur le seul cas Q0 propre, c'est l'**ensemble** (par son bord) qui gouverne, pas la métrique. Deux paramétrisations de (presque) le même S échouent : `blockp` (rang perdu sur ∂S, κ ≤ 440) et `blockh` (rang plein, κ → 1e7). Le libre réussit hors de S.

## Limites

- Adam seulement : la branche GD n'est pas valide (REN GD = 0,59 sur la graine 0 ; tous les bras échouent en GD à 2000 itér.). T1–T3 portent sur GD ; la lecture par T3 reste qualitative.
- Un seul pas par bras, choisi sur la graine 0. P-sat (0,20 à 0,51) est cohérent avec le sweep d'origine (0,18 à 0,37, meilleur pas par graine).
- P-int à 0,9ρ touche ∂S au premier pas : il ne teste pas un run qui resterait à l'intérieur. Une init plus profonde n'est pas testée.
- r est une borne suffisante (certificat). F hors de S n'est pas forcément instable : son test sur 300 pas reste bon (≤ 0,022) avec un entraînement sur 100 pas. Question ouverte, hors M2 : la solution trouvée par F est-elle contractante malgré r ≈ 56 ?

## Suite (table de décision de la roadmap)

Ligne « bord » → faire varier la marge du maître. Test proposé : maître à marge large (par ex. ρ_maître = 0,5). Prédictions à écrire avant calcul : si F sort encore de S et si P-sat échoue encore, la sortie vient du paysage ou de l'init, pas de la position du maître. M3 (riemannien) n'est pas nécessaire : par T3, si le libre sort de S, il n'y a pas de flot riemannien à comparer.
